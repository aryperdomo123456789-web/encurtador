## Objetivo

Entregar um caminho unico para o Lovable:

- entender o escopo;
- priorizar o trabalho por impacto;
- separar o que pertence ao motor Shlink e o que pertence ao futuro `me.vr766.com`;
- iniciar sem ambiguidade de arquitetura.

## Como usar

- Comece pelo backlog P0.
- Não avance para P1 enquanto houver bloqueio estrutural.
- Use a pasta `sites/me.vr766.com` como esqueleto futuro do segundo ambiente.
- Mantenha a documentacao atualizada junto com a implementacao.
